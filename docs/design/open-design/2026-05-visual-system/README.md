# AppFinanzasSDD Visual System References

Open Design generated these files in May 2026 as visual references for the AppFinanzasSDD dashboard and design system.

## Decision

Use this direction as the implementation base:

- Dark premium finance mood
- Lime primary CTA and positive status accent
- Violet guidance and insight accent
- Rounded cards with subtle depth
- Semantic financial states: `vas bien`, `atención`, `zona roja`

## Files

| File | Purpose |
|------|---------|
| `appfinanzassdd-production-system.html` | Visual system overview generated by Open Design. |
| `screens_06-production-desktop.html` | Desktop dashboard reference. |
| `screens_07-production-mobile.html` | Mobile dashboard reference. |
| `screens_08-ui-style-guide.html` | Colors, cards, buttons, badges, progress and state references. |

## Usage Rules

- Treat these files as design references, not production source code.
- Do not copy inline HTML/CSS directly into the app.
- Extract reusable tokens and React components from the direction.
- Keep production implementation in `client/src` aligned with the SDD change `implement-visual-system-dashboard`.
- Prefer semantic tokens over hardcoded colors.

## Out of Scope

- Backend behavior changes
- Full app redesign in one pass
- Runtime dependency on these HTML files
